
# Amazon Product Data Cleaning & Reporting

## Overview
This project uses Microsoft Excel to clean, validate, analyze, and report on an Amazon product catalogue containing 1,000 records and 55 original columns.

## Business Objective
Improve the usability and reliability of product data and summarize product categories, customer ratings, pricing, and data-quality issues.

## Tools Used
- Microsoft Excel
- Power Query
- PivotTables and PivotCharts
- Excel formulas

## Project Workflow
1. Audited the raw dataset.
2. Checked duplicates and missing values.
3. Standardized prices, dates, and source labels.
4. Extracted top-level product categories.
5. Validated fields and documented cleaning decisions.
6. Built PivotTables, charts, and a reporting dashboard.
